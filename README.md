# EditAI Studio

Independent web version of the EditAI iOS video editor. React, TypeScript, Cloudflare Workers, browser FFmpeg and Publik AI. The original iOS application and existing private marketing website remain separate and unchanged.

Development: `codex/publik-web`. Node 22.13+; `npm ci`, `npm run dev`, `npm run build`. Runtime secrets belong in the hosting provider, never browser assets. Implementation and validation status: `plan.md`.
